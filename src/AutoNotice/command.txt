# AutoNotice 定时提醒配置（command.txt）
#
# 每行一条：星期 时间 提醒内容
#   星期：1=周一 2=周二 3=周三 4=周四 5=周五 6=周六 7=周日
#         也可以写 0 或 * 表示每天，或者写 周一 / 一 / Mon
#   时间：24 小时制，例如 08:00、12:30（也接受 8:00 与 1200）
#   内容：提醒文字，可以带空格
#
# 以 # 或 ; 开头的行是注释；某一行写错只会跳过该行，不影响其他提醒。
# 编辑完成后回到 LTFC 的「AutoNotice → 设置」点“重新读取”即可生效。
#
# 下面是可以直接改的示例：

1 08:00 早读开始，请同学们拿出课本
1 12:00 午休时间
5 15:30 大扫除
* 17:30 提醒学生带走随身物品
