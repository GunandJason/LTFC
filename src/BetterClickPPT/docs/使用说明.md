# PPT 触摸增强工具 使用说明（给使用者的简明版）

## 一、这是什么

**PPT 触摸增强工具**是一款面向触摸屏 / 触摸一体机的 PPT 放映增强工具。
在触摸屏 / 触摸一体机上放 PPT 时，手指“点一下屏幕”往往没有反应，只能用手指滑动翻页；
安装本程序后：**手指轻点屏幕即可直接翻到下一页**，同时兼容 PowerPoint 与 WPS 演示。

程序只增强“全屏 + 无边框”的放映窗口，编辑 PPT 时的点击完全不受影响；
安装与运行都不需要管理员权限。

安装完成后程序常驻右下角托盘，不需要额外操作：打开 PPT / WPS，按 **F5** 开始全屏放映，
**手指轻触屏幕**即可继续（与鼠标左键点击完全一致：页内动画逐帧播放、动画播完才翻下一页，
超链接和屏幕上的“上一页 / 下一页”按钮也都能点；滑动翻页、双指缩放保持原有行为）。

## 二、怎么安装

1. 双击 **BetterClickPPT-Setup.exe**。
2. 第一步会显示“欢迎”，点「开始安装」。
3. 向导会自动检测本机的 PowerPoint / WPS 演示安装位置：
   - 显示“已检测到”即为成功（同时显示来源和版本）；
   - 如果没检测到，点「浏览…」手动选择主程序（PowerPoint 是 `POWERPNT.EXE`，WPS 演示是 `wpp.exe`）。
4. 勾选你要为哪个软件启用（可以只选一个，也可以两个都选）。
5. 选择安装位置（默认位置即可，不需要管理员权限）、是否开机自启、是否要桌面快捷方式。
6. 点「开始安装」，完成后可勾选立即启动。

> 卸载：开始菜单里找到 PPT 触摸增强工具 右键删除，或在“设置 → 应用 → 已安装的应用”中卸载。

## 三、怎么用

| 操作 | 效果 |
| --- | --- |
| 手指轻触屏幕 | 下一页 |
| 手指左右滑动 | 保持原样（下一页 / 上一页，由 PowerPoint 处理） |
| 双指缩放、长按 | 保持原样 |
| 鼠标左键点击 | 保持原样 |
| 编辑 PPT 时点击 | 完全不受影响 |

托盘图标（右下角）：

- **双击** → 打开设置；
- **右键** → 暂停/启用、设置、检测当前前台窗口、打开日志文件夹、关于、退出。

## 四、常见问题

**1. 点屏幕还是没反应？**

打开设置 → 「翻页行为」→ 勾选「**深度触控模式**」，保存。
（有些电脑的触摸输入被 PowerPoint 自己“吃掉”，系统不会把它当成鼠标点击，因此需要直接监听触摸屏。）

**2. 点一下发生了两次？**

打开设置 → 「翻页行为」→ 确认「**吞掉触摸原始点击**」已勾选（默认勾选）。

**3. 页内动画没播放 / 超链接点不开 / 屏幕上的“上一页”按钮点不到？**

打开设置 → 「翻页行为」→ 把「**轻触的处理方式**」设为「**模拟鼠标点击**」（默认值），
保存后轻触就会被原样还原成一次鼠标左键点击：
分步动画逐帧推进、动画播完才翻页、超链接和“上一页 / 下一页”按钮都能正常使用。

**4. 想用触摸回到上一页？**

- 用手指滑动（滑动始终交给 PowerPoint / WPS 自己处理）；
- 或轻触屏幕上的“上一页”按钮（「模拟鼠标点击」模式下可用）。

**5. 想确认程序是否识别到了放映窗口？**

托盘右键 →「**检测当前前台窗口**」，应看到“匹配结果：命中规则「Microsoft PowerPoint」”。

**6. 我想把日志发给开发者？**

托盘右键 →「打开日志文件夹」，把 `betterclickppt.log` 发过去即可。
需要更完整的环境信息时，在命令行执行：`BetterClickPPT.exe --detect > 报告.txt`。
报告里也会显示「**自动切回鼠标模式**」当前是开启还是关闭。

**7. 支持 WPS 吗？**

支持。安装时勾选“WPS 演示”，或在设置 →「目标软件」中随时启用。
若 WPS 版本较新、识别不到，可在设置 →「自定义程序」中添加进程名 `wpp.exe`。

**8. 放映时 PowerPoint 的按钮变得很大、单击被当成手势？**

这是 PowerPoint / WPS 演示的“**触摸模式**”。打开设置 →「翻页行为」→ 确认
「**放映开始时自动切回鼠标模式**」已勾选（默认开启）：程序会在**进入放映时自动把它切回鼠标模式**，
只对 PowerPoint / WPS 演示生效，不需要你每次手动去点那个按钮，也不会影响其它程序。
（成功时日志里会写 `已自动把 Office 切回「鼠标模式」…`；本来就是鼠标模式时会写 `无需切换`。）

## 五、高级用法（给 IT / 批量部署）

```powershell
# 静默安装：两个软件都启用，不开机自启、不建桌面快捷方式
BetterClickPPT-Setup.exe --install --ppt --wps --no-autostart --no-desktop --quiet

# 查看环境检测报告
BetterClickPPT.exe --detect

# 列出 PPT / WPS 的窗口并显示是否命中识别规则
BetterClickPPT.exe --probe

# 静默卸载
BetterClickPPT.exe --uninstall --quiet
```
